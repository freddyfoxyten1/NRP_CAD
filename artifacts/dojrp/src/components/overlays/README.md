Full-screen overlays, modals, and slide-in panels.

| File | What it does |
|---|---|
| `LoginModal.tsx` | Authentication modal — Discord OAuth login and local test accounts. |
| `IncomingCallOverlay.tsx` | Full-screen alert overlay shown when an incoming phone call arrives. |
| `PhonePanel.tsx` | Slide-in panel for the in-app comms / phone system. |
