# components/shared/

Small reusable components used across multiple pages.

| File | What it does |
|---|---|
| `DojrpLogo.tsx` | DOJRP brand logo (SVG). Used in nav bars and the login modal. |
| `LiveClockBadge.tsx` | Real-time clock badge — updates every second. |
| `LastUpdatedBadge.tsx` | Shows a human-readable "last refreshed X seconds ago" timestamp. |
| `made-with-dyad.tsx` | Small branding badge. |
