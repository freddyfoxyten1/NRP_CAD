# components/editor/

Components that make up the DPS document editor.

| File | What it does |
|---|---|
| `DocumentEditor.tsx` | The full document editor — multi-page layout, toolbar, tables, images, PDF import, per-page styling. Built on TipTap / ProseMirror. |
| `ImageOptionsPanel.tsx` | Floating panel for resizing and aligning an image selected inside the editor. |
| `ImageView.tsx` | Custom TipTap node view that renders a draggable, resizable inline image. |
