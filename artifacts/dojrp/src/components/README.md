# components/

Organised into four sub-folders:

| Folder | Contents |
|---|---|
| `editor/` | Rich-text document editor (TipTap) and image panel components |
| `overlays/` | Full-screen overlays, modals, and slide-in panels |
| `shared/` | Small reusable brand and utility components |
| `ui/` | Auto-generated shadcn/ui primitives — **do not hand-edit** |
